02 Framework de Produccion
Cada pieza creativa se define con 5 dimensiones del framework de produccion. Esta guia explica cada dimension para que el equipo pueda interpretar las fichas de cada pieza correctamente.
Pilar y Tema
El pilar es el eje estrategico del contenido (ej: Identidad de Marca, Producto, Educacion). El tema es el angulo especifico dentro del pilar (ej: bajo el pilar Producto, los temas pueden ser "Variedad artesanal", "Conveniencia", "Meal prep"). Pilar y tema son especificos de cada cliente y se definen en la estrategia.
PILAR → TEMA → Contenido de la pieza
Ejemplo: Pilar "Producto" → Tema "Variedad y calidad artesanal" → Video de degustacion del Mix.
Formato Narrativo
Define como se cuenta la historia, no el formato tecnico (video/posteo). Cada formato narrativo tiene sub-variantes que se pueden usar segun la pieza.

Tono de comunicacion
Cercano, directo, sin formalidades. Habla como un amigo que te recomienda algo que realmente le gusta. Evitar lenguaje corporativo o demasiado publicitario. Priorizar autenticidad y prueba real sobre claims genericos.
